# Changelog

## 0.1.0 — public beta

- Find supported asset properties by ID, Roblox URL, or pasted asset error.
- Browse an asset inventory and search readable script text without editing scripts.
- Preview selected property replacements and apply them as one Studio undo operation.
- Skip stale or deleted targets and report write failures.
- Cancel scans and browse paginated results.
- Wrap full paths and values in replacement previews, including at the minimum panel size.
- Reset scroll when changing pages while preserving it for selection changes.

This beta does not diagnose asset availability or permissions. MeshPart geometry and script text remain read-only.
