# Security policy

## Supported versions

Security fixes target the latest published beta or release. Update before reproducing an issue when possible.

## Report a vulnerability privately

Use [Report a vulnerability](https://github.com/Zackslay/asset-medic/security/advisories/new) in this repository's **Security** tab. Do not disclose exploitable details in a public issue or the support server.

Include:

- Asset Medic and Roblox Studio versions.
- A minimal reproduction, expected behavior, and actual behavior.
- The possible impact, such as unintended property changes, script execution, or data exposure.
- Any relevant logs, with credentials and private project information removed.

Test only on places you own or have permission to test. Use a disposable copy and avoid disrupting other users. Give the maintainer time to investigate and coordinate a fix before publishing details. This project does not offer a response-time guarantee or bug bounty.

## Ordinary bugs

Use [GitHub issues](https://github.com/Zackslay/asset-medic/issues) for non-security bugs and [Discord](https://discord.gg/4cxQwKtY3q) for general support. Asset availability, moderation, and permission errors alone are not plugin vulnerabilities.
